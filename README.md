## Cara membaca repository saya

Tidak semua repo di sini layak dijadikan portofolio, dan saya lebih jujur soal itu daripada mempercantiknya:

- Sebagian adalah **titipan** — website kecil yang saya buatkan untuk teman. Saya tidak mempublikasikannya atas nama mereka.
- Sebagian adalah **kerangka awal** yang belum saya selesaikan.
- Yang saya anggap serius hanya yang ada di tabel di atas.

Deskripsi dan topic tiap repo sedang saya rapikan supaya jelas fungsi dan statusnya.
